
# UAV Vision Research Lab

### From Fundamentals to Advanced UAV Computer Vision

A structured learning, engineering, and research journey
focused on computer vision for Unmanned Aerial Vehicles (UAVs).

## Objectives

- Develop expertise in computer vision and image processing.
- Build real-time UAV perception and navigation systems.
- Conduct original academic research.
- Publish peer-reviewed scientific papers.
- Develop research proposals, including TUBITAK 1002.
- Build an industry-oriented technical portfolio.

## Learning Modules

1. Image Processing Fundamentals
2. Classical Computer Vision
3. Deep Learning for UAVs
4. Visual Odometry and SLAM
5. Real-Time and Embedded Vision Systems
6. Advanced Research and Scientific Publications

## Research Areas

- Aerial Object Detection
- Multi-Object Tracking
- Small Object Detection
- Visual Navigation
- Visual Odometry and SLAM
- Real-Time AI Systems
